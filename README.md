# Exam App

This is a starter Android Studio project for an online exam application.

## Current features

- Exam home screen
- MCQ questions
- Radio-button answer selection
- Countdown timer
- Automatic submission when time ends
- Manual submission
- Automatic score calculation
- Result screen

## Next stage: online multi-user version

The next version should connect this app to Firebase:

- Firebase Authentication for student/admin accounts
- Firestore for exams, questions, users and submissions
- Admin dashboard to create exams
- Published exams visible to students
- Online result storage
- Leaderboard
- Negative marking
- Exam attempt control

## Open

Open the `ExamApp` folder in Android Studio and let Gradle sync.
